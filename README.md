# Customer Lifetime Value (CLV) Prediction

This project predicts **Customer Lifetime Value (CLV)** by analyzing historical transactional data to estimate future customer revenue.

## 🚀 Live Demo
🔗https://bdoqrdspkfu2uhtsjpmb7s.streamlit.app/

## 📌 Problem Statement
Businesses need to identify high-value customers to optimize marketing, retention, and loyalty strategies.  
This project addresses this by predicting the expected future revenue generated by each customer.

## 🧠 Solution Approach
- Transformed raw transaction-level data into customer-level behavioral features  
- Engineered RFM-based features (Recency, Frequency, Average Spend, Tenure)  
- Trained a regression model using a time-based split to avoid data leakage  
- Predicted future revenue over a defined time window  
- Deployed the solution as an interactive Streamlit web application  

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## 📂 Dataset
For deployment purposes, a **sampled subset** of the original dataset is included.  
Users can also upload their own CSV file with the same schema.

Required columns:
- customer_id
- transaction_date
- transaction_amount

## 📊 Output
The application outputs a ranked table of customers with their predicted lifetime value.

## 📈 Use Cases
- Customer segmentation
- Targeted marketing
- Retention strategy planning
- Revenue forecasting
